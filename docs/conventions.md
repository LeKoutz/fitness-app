# Conventions

How we write code in this project. Issues, branches, commits and pull requests follow the
collaboration rules in the `Start Here` issue.

## Formatting

- Code is formatted with Prettier, using its default settings.

## Frontend

- Frontend is designed in [Penpot](https://design.penpot.app/?screen=viewer&file-id=b4b906dd-9024-819c-8008-ee6926f4a1ce&page-id=b4b906dd-9024-819c-8008-ee6926f4a1cf&section=interactions&index=0&share-id=71bbd7a3-da14-4ad8-b697-1c426787fec0https://design.penpot.app/?screen=viewer&file-id=b4b906dd-9024-819c-8008-ee6926f4a1ce&page-id=b4b906dd-9024-819c-8008-ee6926f4a1cf&section=interactions&index=0&share-id=71bbd7a3-da14-4ad8-b697-1c426787fec0) first.
- We aim to follow it as a guide rather than evangelion.
- You may decide to deviate from it if code gets simpler, UX gets easier or if something is outdated. When you do, say why in the Pull Request.
- You may also use it to design a component before it reaches the codebase.
